# 页面说明

7 页，实现在 `ui/pages/`，路由表在 `app.py::PAGES`。这份文档除了"能看到什么"，重点写**代价与边界**——哪些操作慢、覆盖面到哪，因为这些是页面上最容易被误读的部分。

## 全局信号总览（`ui/pages/overview.py`）

股票池里所有标的的一张表：市场、名称、昨收、现价、涨跌幅、市盈率、信号值、推荐、仓位建议。

- **扫描范围**可按类型勾选（指数 / 板块 / 个股）。**未选中的类型既不扫描也不渲染**——不是"折叠起来"，Streamlit 的折叠区里内容照样渲染。范围进扫描指纹，改了就重扫。
- **代价是不对称的**：个股 + 指数走腾讯批量接口，几十个一次约 0.2s；板块**没有批量行情接口**，逐个同花顺快照约 0.74s/个，95 个板块 ≈ 70s。所以只想看个股时把板块取消勾选能省一分多钟。
- 一个分组超过 `COMPACT_ROWS`（20）行时改用紧凑表格：一个 `st.dataframe` + 表下的"看某个标的的详情"选择器，替代逐行 9 列 + 按钮（95 行逐行渲染约 950 个 widget，光渲染就卡）。≤20 行保持逐行按钮。
- 组头给摘要（`板块（95 个 · 买入 3 · 卖出 12 · 观望 80）`），并有"只看有信号的"开关。
- 扫描结果按信号源缓存在 `st.session_state`，股票池或范围变化才重扫。

## 单股票分析（`ui/pages/detail.py`）

选标的 → 选时间范围 → 点"开始分析"。给出 K 线 + 布林带 + MACD + RSI/KDJ、各维度信号判定、回测净值与交易明细、以及两张卡片：

- **情绪卡**（`ui/cards.py`）：近 10 个交易日的新闻/公告/股吧条目 + 情绪分，模型是本地中文金融情绪模型（transformers，CPU 推理），不打任何外部 LLM API。
- **基本面卡**：营收/净利/ROE/资产负债率的趋势判定与 flags，只覆盖 A 股个股（接口所限）。

**Kronos 预测在这一页手动触发**：单只在 CPU 上约 40 秒，因此不进总览页扫描、不进板块选股、也不进对话工具。

## 新闻列表（`ui/pages/news_list.py`）

池内标的的新闻/公告/股吧汇总，可按来源过滤。采集与情绪打分**只在访问时写入**；删除由每日 03:00 的定时任务统一做（窗口为过去 10 个交易日）。

## 股票池管理（`ui/pages/manage.py`）

搜索全市场 A 股/港股加入，或手工输代码；指数与板块同样在这里加。**支持按行业/概念批量加板块**——批量添加是一次读 + 一次写，不是 N 次读写 json。

加板块要留意后果：板块越多，总览页与板块分析的取数越贵（见上面的 0.74s/个）。

## 板块分析（`ui/pages/sector.py`）

三个视图合在一页：

**相关性**：板块两两相关系数。三种模式——原始、剔除沪深300（回归取残差）、剔除板块横截面均值。
- 板块数 ≤ `HEATMAP_MAX`（25）画全矩阵；超过就默认给**抱团分组清单** + "画哪一组"选择器 + 自定义勾选（95×95 = 9025 格缩到屏幕宽度后数字全糊）。
- 格子多时（> `CELL_TEXT_MAX`，15）不写格内数字，只留颜色，hover 给三位小数。
- "相关对排行"给最负 15 对（对冲候选）与最正 15 对（抱团最紧），这两张表与板块数无关，大 N 下才是主要读法。

**轮动**：各板块在 5/20/60 日窗口的收益、超额收益（减沪深300 同期）、池内排名，据排名迁移给出四种确定性标签（持续走强 / 新晋走强 / 转弱 / 持续弱势），再叠加资金流。
- 动量类指标**只算池内板块**（板块日K要逐个取）；资金流排行是**全市场**的（一次调用返回全部且已排序，免费）。
- 沪深300 取不到时超额退回绝对收益，并标注 `index_available=False`——不标注会被误读。

**板块内选股**：挂在热度分排名下方。两级漏斗——用成分股接口自带的涨跌幅粗筛前 `SECTOR_PICK_TOP_N`（20）只（免费），只对这些做技术/缠论信号 + 基本面 + 相对板块超额的细算。
- 返回值同时给"总成分股数"与"实算数"，页面照原样显示。**不许静默截断**。
- 成分股缓存 7 天，取数失败回落过期缓存并标 `stale` + 缓存日期；粗筛用的涨跌幅可能是几天前的快照，页面必须说明。
- 匹配不到东方财富板块时选股入口禁用，并给出原因与候选名（人工写进 `config/em_board_alias.json`）。

## 自定义策略（`ui/pages/custom_strategy.py`）

挂载"交易策略 / 仓位管理"层：内置两个（默认强度分档、装死四分之一），`strategy/custom/*.py` 里的会被自动发现。

还有**自然语言生成策略**面板：描述需求 → 模型产出策略源码 → 三道闸门（结构提取 → AST 静态校验 → 子进程冒烟回测）→ 通过才落盘启用，失败归档到 `_rejected/`。生成在独立进程里跑，可轮询、可杀。用哪家模型由 provider 决定，SDK 缺失时面板会给出可直接复制的 pip 命令。

## AI 分析助手（`ui/pages/chat.py`）

把上面的确定性函数包成模型工具（`analysis/chat/tools.py`），模型只做意图路由、跨源综合和追问，排序/聚合/加权仍由 Python 完成。

- 工具的边界写进 JSON Schema（例如资金流只有五个固定档位，写成 enum 后模型在 schema 层就传不出别的值）。
- 重计算类工具有硬上限：板块选股 `top_n ≤ 30`，总览扫描**只读缓存**、缺失就回不可用 + 提示，不在对话回合里现算全池。
- **Kronos 不在工具集里**（同样是 40 秒/只的理由）。
- 每次回答带工具调用轨迹，可展开看模型到底调了什么、拿到什么。
